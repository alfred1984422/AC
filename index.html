💣 地雷一：排偶數時「含 0 未分類」

題目：用 0, 2, 4, 5, 6, 8 組成無重複數字的四位偶數。

❌ 錯誤直覺寫法：

直接寫「個位 5 選 1，千位 5 選 1」會出錯！因為當個位選 0 時千位有 5 種選擇；當個位選 2,4,6,8 時千位不能為 0 只有 4 種選擇！

✅ 正確標準解法：

必須分兩類相加：① 個位是 0 有 個；② 個位不是 0 有 個，合計 60 + 192 = 252 個！

💣 地雷二：相同數字忘記「除以階乘消序」

題目：排圓周率 3, 1, 4, 1, 5, 9 或世界讀書日 2, 0, 2, 5, 4, 2, 3。

❌ 錯誤直覺寫法：

把兩個相同的 1 插入 5 個空隙誤用排列數；或將含三個 2 的七位數直接算全排列而忘記除以重複數字的階乘。

✅ 正確標準解法：

相同數字交換位置仍是同一個數！兩個相同 1 插 5 空隙用組合 ；含三個相同 2 的全排列必除以 消序！

💣 地雷三：雙面卡片或對數底真數隱藏重複

題目：4 張卡片正反面為 (1,2) (1,3) (4,5) (6,7) 排四位數，或取兩數算 lg a - lg b。

❌ 錯誤直覺寫法：

沒注意到第 1、2 張卡片正面都是數字 1！或在 lg(a/b) 中忽略了 2/4 = 4/8 比值相等！

✅ 正確標準解法：

雙面卡片按 1 的個數分三類：96 + 192 + 48 = 336 個；對數相異值需扣 2 組重複：20 － 2 = 18 個！
